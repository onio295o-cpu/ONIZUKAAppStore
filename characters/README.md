# キャラクター画像の置き場

ここに画像（PNG 推奨・背景が透明だときれい）を置くと、ごほうびシーンにそのキャラが登場します。
**画像が無いキャラは出てきません**（仮の絵はありません）。画像なしで出るのは「うんちぼうぼう」だけです。

| ファイル名 | 役 | 初期設定の名前 |
|---|---|---|
| `boy.png` | 主役の男の子 | のび太 |
| `bully.png` | 大きい友だち | ジャイアン |
| `villain.png` | 鼻毛で宇宙へ連れていく悪役（上から出てきます） | ボーボボ |
| `hero.png` | ヒロイン（ホーム画面の応援にも出ます） | プリキュア |
| `guest1.png` | ゲスト1 | ピカチュウ |
| `guest2.png` | ゲスト2 | パウ・パトロール |
| `guest3.png` | ゲスト3 | ビッピー |

- 名前・声の高さ・鼻の位置は `index.html` の `CAST` で変えられます。
- 宇宙のシーンは `boy.png` と `villain.png` の両方があるときに出ます（`bully.png` があれば道づれ、`hero.png` があれば動画つきでやっつけます）。
- `villain.png` は、鼻の位置から鼻毛が伸びます。位置は `nose: {x, y}`（画像の幅・高さに対する割合）で調整します。
- 画像は横幅 150〜300px くらいで十分です。
