# キャラクター画像の置き場

ここに画像（PNG 推奨・背景が透明だときれい）を置くと、ごほうびシーンで自動的に使われます。
ファイルが無いキャラは、仮の絵になります（ゲストは出てきません）。

| ファイル名 | 役 | 初期設定の名前 |
|---|---|---|
| `boy.png` | 主役の男の子 | のび太 |
| `bully.png` | 大きい友だち | ジャイアン |
| `villain.png` | 宇宙へ連れていく悪役（上から出てきます） | ボーボボ |
| `hero.png` | ヒロイン | プリキュア |
| `guest1.png` | ゲスト1 | ピカチュウ |
| `guest2.png` | ゲスト2 | パウ・パトロール |
| `guest3.png` | ゲスト3 | ビッピー |

- 名前・声の高さ・鼻の位置は `index.html` の `CAST` で変えられます。
- `villain.png` は、鼻の位置から鼻毛が伸びます。位置は `nose: {x, y}`（画像の幅・高さに対する割合）で調整します。
- 画像は 横幅 150〜300px くらいで十分です。縦長の全身絵ならそのまま使えます。
