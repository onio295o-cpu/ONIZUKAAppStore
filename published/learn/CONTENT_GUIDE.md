# 学習コンテンツの作り方（さんすうパーティー）

対象：4〜6歳。保護者が自分の子どもに使う家庭用アプリ。

## ファイル
- `learn/data/subjects.json`：教科の一覧（ここは Claude 本体が更新する。各担当は触らない）
- `learn/data/<教科>.json`：教科ごとのステージと問題
- `learn/learn.js`：画面と問題の種類（TYPES）。既存の種類を使う

## 教科データの形（sansu.json と同じ）
```json
{
  "subject": "kokugo", "version": 1,
  "tracks": {"kana": {"title": "ひらがな", "icon": "あ", "say": "ひらがな"}},
  "courses": {
    "4": [ {"id": "kg4-a1", "track": "kana", "title": "あ〜お を よもう", "q": [ 問題, … 10問 ] } ],
    "5": [ … ], "6": [ … ]
  }
}
```
- `track` は同じゲームのまとまり。同じ track の前のステージで星1つ以上取ると、次が開く。track を使わない教科なら省略してもよい。
- 1ステージは10問。星は正解数で決まる（9問以上で星3つ、7問以上で星2つ、5問以上で星1つ）。
- `id` は教科の中で重ならないようにする。

## 表記
- ふりがな：`{漢字|かんじ}`。4歳はひらがなだけにする。5〜6歳は漢字にふりがなを付ける。
- 文は短くし、分かち書き（言葉の切れ目に空白）にする。例：「どれが りんご かな？」
- 読み上げはブラウザが行う。文末の「は」は自動で「わ」と読む。

## 問題の種類

### quiz：見せるものを見て選ぶ
```json
{"t":"quiz","text":"これは なんて よむ？","show":{"big":"あ"},"choices":["あ","お","め"],"ans":"あ","hint":"くちを おおきく あけて いう おとだよ","expl":"「あ」は あり の あ"}
```
- `show` はどれか1つを使う。
  - `{"big":"文字や絵文字"}`（大きく表示。`"small":true` で少し小さくなる）
  - `{"pics":["🍎","🍎"]}`（絵文字を並べる）
  - `{"flag":"🇯🇵"}`（国旗の絵文字）
  - `{"planet":"earth"}`（惑星の絵。使えるのは sun / mercury / venus / earth / mars / jupiter / saturn / uranus / neptune / moon / pluto）
  - `{"planets":["mercury","earth","jupiter"]}`（本当の大きさの比で並べる）
  - `{"text":"短い文章"}`（読み取り問題の本文）
- `choices`：選択肢。4歳は3つ、5〜6歳は3〜4つ。
- `ans`：正解の文字列（choices の中の1つ）か、正解の番号。
- `cbig`：`true` にすると選択肢を大きく表示する（1文字や絵文字の選択肢のとき）。
- `hint`：1回目に間違えたときに読み上げる。答えをそのまま言わない。
- `expl`：答えのあとに表示して読み上げる説明。短く、豆知識を1つ入れる。
- 英語用：`"en":"apple"` を付けると英語で読み上げ、🔊ボタンも出る。`"enChoices":true` で、選択肢を押すたびに英語で読む。

### order2：正しい順番にタップ
```json
{"t":"order2","text":"ちいさい じゅんに ならべよう","items":["mercury","mars","earth"],"planets":true,"labels":["{水星|すいせい}","{火星|かせい}","{地球|ちきゅう}"],"expl":"…"}
```
- `items` は正しい順番で書く（画面ではバラバラに並ぶ）。`planets:true` なら items は惑星ID で、`labels` が表示名になる。
- planets を使わないときは、items に文字を入れる（例：しりとりの順番、お話の順番）。

### repeat：英語を聞いて2回言ってみる（練習なので、いつも正解あつかい）
```json
{"t":"repeat","en":"Good morning","ja":"おはよう","show":{"big":"🌅"}}
```

## 確認のしかた
- JSON として正しいこと（`node -e "JSON.parse(require('fs').readFileSync('learn/data/xxx.json','utf8'))"`）。
- 全問について、`ans` が `choices` に入っていること、選択肢に重複がないこと、id が重ならないこと、1ステージ10問であることを、確認用スクリプトでチェックする。
- 事実が正しいこと（国名・首都・惑星の順番など）。子ども向けでも、まちがいは入れない。
- 怖い内容や不適切な内容は入れない。
